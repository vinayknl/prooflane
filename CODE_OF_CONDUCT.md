# Code Of Conduct

Prooflane follows a simple standard: be respectful, precise, and evidence-led.

Good collaboration here means:

- Assume good intent.
- Critique code and claims, not people.
- Separate facts, inference, and decisions.
- Keep feedback actionable.
- Avoid exposing private data, credentials, or confidential repository content.

Unacceptable behavior includes harassment, personal attacks, deliberate
misrepresentation, and knowingly publishing secrets or private data.

For now, moderation is handled by the repository owner.
